# Next.js 15 + TypeScript + Tailwind CSS + shadcn/ui

A starter app using Next.js App Router, TypeScript, Tailwind CSS, and a small shadcn-style component library.

## Setup

1. Open the project folder:
   ```bash
   cd C:\Users\GS\next15-shadcn-tailwind-app
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Available scripts

- `npm run dev` — start development server
- `npm run build` — build for production
- `npm run start` — start production server

## App structure

- `app/` — App Router pages and layout
- `components/ui/` — reusable UI components styled for Tailwind
- `lib/utils.ts` — shared utility helpers
